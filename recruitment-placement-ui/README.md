# Recruitment & Placement Management System — UI Prototype

A responsive, technology-neutral HTML/CSS prototype based on the supplied Kiran Academy specification.

## Included
- All 12 HTML pages: login, dashboard, candidates, candidate form, candidate details, companies, jobs, job form, applications, interviews, placement process, reports.
- Shared responsive stylesheet in `css/style.css`.
- Logo asset in `images/logo.svg`.
- Realistic sample data and working page-to-page navigation.

## Run
1. Extract the ZIP file.
2. Open `login.html` in Chrome, Edge, or Firefox.
3. Click **Login** to open the dashboard and use the sidebar to navigate.

No installation, server, database, Java, or Python backend is required. Forms and action buttons are visual prototype controls and do not persist data. The login button links to the dashboard.

## Notes
- Demo account shown on the login screen: `recruiter@demo.com`
- This is a static front-end prototype, not a production recruitment system.
